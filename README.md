# MeowAi

本地优先的 Windows 桌面 AI 助理客户端。对话、资料库、模型配置都在本机完成，文件不出本地，密钥只存在自己的电脑上。

当前版本：**v0.2.8**

## 这是什么

MeowAi 把“和大模型对话”和“查自己的文档”放在同一个窗口里。你可以接入自己的 API Key，在对话里直接引用本地资料库检索到的内容；也可以把某个文档库的切片、向量索引和图片描述全部留在本地，只在需要回答时把命中的片段发给模型。

它面向的是愿意自己管理密钥、又不想把资料上传到第三方知识库的 Windows 用户。没有账号体系，不需要注册，不经过任何中转服务器，请求由客户端直接发往你选择的模型厂商。

三条设计取舍贯穿整个应用：

- **本地优先**：会话、资料库、配置、密钥都在本机。检索和切片不联网，只有模型请求会离开本机。
- **厂商无关**：内置厂商目录 + 自定义 OpenAI 兼容端点，换厂商不改界面，模型列表可以现场拉取。
- **状态可见**：密钥是否有效、当前模型、检索参数、Token 消耗与耗时都直接显示，不藏在日志里。

## 快速开始（普通用户）

1. 运行安装包 `MeowAi-Setup-0.2.8.exe`。按当前用户安装到 `%LOCALAPPDATA%\Programs\MeowAi`，不需要管理员权限。
2. 首次运行会播放内置开屏动画，可点右上角“跳过”。
3. 打开次顶部 Dock 的“配置”，填入厂商、模型与 API Key，点“验证”确认可用。
4. 进入“资料库”导入文件，在右侧配置抽屉里设置 embedding 模型，等索引完成后即可在对话中引用。

安装包未签名，Windows 首次运行会提示 SmartScreen，需要点“更多信息 → 仍要运行”。

完整操作步骤见 [docs/USER_GUIDE.md](docs/USER_GUIDE.md)。

## 界面结构

窗口从上到下分四层：

| 区域 | 作用 |
|---|---|
| 标题栏 | 拖动、最小化、最大化/还原、关闭。最大化后按住标题栏拖动会还原为普通窗口并跟随光标 |
| 左侧导航栏 | 新建对话、对话列表、角色卡、个性化、资料库、技能仓库。右上角可缩回成窄条，窄条顶部有展开按钮 |
| 次顶部 Dock | 当前页面标题 + 模型胶囊 + “配置”按钮。模型胶囊常驻，点开后可切换模型、拉取模型列表 |
| 内容区 | 对话页、个性化页、资料库页、技能仓库页。资料库的配置面板从右侧滑出，默认不占位 |

窗口为无边框圆角窗口，四角自绘；最大化时自动取消圆角。

## 功能详解

### 对话

- **流式输出**：SSE 逐段渲染，输出过程中可随时停止。
- **Markdown 渲染**：模型返回的 Markdown 由 `QTextDocument` 转成富文本，标题、列表、代码块、表格按排版显示，长内容限制气泡宽度。
- **回答操作条**：每条回答底部有复制、重新生成、分享文字、分享图片四个图标动作，hover 显示功能名，右侧显示本次消耗的 Token 与耗时。
- **思考档位**：按厂商能力提供关/低/中/高四档，随请求下发，不支持的厂商自动隐藏。
- **上下文管理**：会话落库、上下文裁剪与流式节流都在 core 层完成，界面只读模型。
- **错误呈现**：网络错误、密钥错误、资料库错误统一显示在对话页顶部，不弹遮挡式对话框。

### 模型接入

内置厂商目录：OpenAI、DeepSeek、通义千问、Kimi、智谱、Anthropic，外加“自定义”OpenAI 兼容端点。

- 每个厂商预置模型清单，配置面板里可“拉取模型”从服务端取当前可用列表。
- 自定义厂商需要填写服务地址（Base URL），地址与模型名都存在本地配置中。
- 密钥三态：未配置、已就绪未校验、有效/无效。校验结果带失败原因。
- 资料库的 embedding 与视觉模型各自有独立的厂商、模型、地址与密钥，可覆盖对话配置。
- 密钥通过 Windows DPAPI 加密后写入本地安全存储，不写明文配置文件。

### 资料库

支持导入 `txt / md / csv / json / pdf / docx / xlsx / pptx / png / jpg / jpeg / webp / bmp`。

处理流程：

1. **解析**：文本类直接抽取；PDF 依赖 PDFium（默认不随包分发，需要时运行 `scripts/fetch-pdfium.ps1` 抓取）；Office 文档解析为纯文本。
2. **切片与向量化**：按配置的 embedding 模型切片入库，向量写入本地 SQLite；批量大小按厂商上限自动拆分，避免超过单次请求限制。
3. **图片描述**：图片走视觉模型生成描述后再入库，视觉模型可单独配置。
4. **检索**：本地向量检索 + FTS5 全文检索，命中结果按文件级召回后做三级注入，并按上下文预算裁剪。
5. **参数**：召回数量、切片长度、重叠、注入预算等都在右侧配置抽屉里调整，抽屉同时显示成本预估与库内搜索入口。

配置抽屉默认收起，从次顶部 Dock 的“配置”按钮或资料库页顶点打开。

### 角色卡

把「用什么模型、什么思考档位、什么人格提示词」打包成一张卡，点一下就整套切换。

- **套用**：点侧栏卡片即生效，模型、思考档位、系统提示词三项一起切换；头像只作展示，不影响回答。当前生效卡高亮并标「已套用」，未套用时无高亮。
- **管理**：新增、编辑、删除、导入、导出。名称必填且不可重名，提示词可留空；头像复用 512×512 裁剪。
- **默认值语义**：新建时厂商 / 模型 / 档位三项可选「默认」，含义是「套用时跟随当前正在用的设置」，只有显式改选后才锁定成具体值。这样一张卡可以在多个厂商间通用。
- **导入冲突**：导入时若有同名卡，先只做**预检**并列出冲突名单，由你选覆盖 / 跳过 / 取消，**不选择就不写库**，绝不静默覆盖。
- **删除当前生效卡**：模型与档位保持最后状态，只清空系统提示词，并提示一次。
- **提示词下发**：作为第一条 system 消息发送，排在当前时间、技能与资料库检索内容之前；留空则不下发空的 system 消息。切换只影响下一条消息，不改写历史。

当前生效的角色卡是内存态，重启后回到未套用。

### 技能仓库

把领域知识或固定行为写成技能包，按触发词自动注入，或在输入区手动挑选。

- **两种模式**：自动模式按触发词匹配输入（不区分大小写、支持中文子串），最多同时注入 2 个已启用技能，排序以触发词在输入中首次出现的位置为准；手动模式下在对话输入区选择，仅本次发送生效。
- **启停**：每个技能可单独启停，禁用后永不注入。
- **导入**：`zip` 包，必须含 `manifest.json` 与 `skill.md`。单包 ≤ 20 MB、解压后 ≤ 100 MB、条目 ≤ 2000。条目名走**自解析 zip 中央目录**校验，拒绝绝对路径、盘符、符号链接与多 manifest（`QZipReader` 会把 `../x` 静默改写成 `x`，只有看原始字节才能真拒绝）。与内置技能同 id 会被拒绝并要求改名；与已有导入技能同 id 按覆盖更新。
- **注入预算**：全部技能内容合计超过 4000 字符会硬截断，且不追加任何提示。
- **删除**：内置技能不可删，导入的技能删除只影响本地目录。

### 个性化

- **主题**：内置深色琥珀（Nocturne）与浅色浅蓝（Daylight）两套预设，所有界面颜色取自主题令牌，换主题不会漏色。
- **头像**：选择图片后弹出圆形裁剪，支持缩放与拖动；1 倍率下只要图片在实际方向上超出圆形就能拖动，不会露出底色；确认后导出 512×512 圆形 PNG。
- **字体**：可导入 `ttf / otf / ttc`。
- **开屏动画**：内置琥珀与浅蓝两版，跟随当前主题选择，含合成音效；支持替换为自己的视频、预览、清除、声音开关。未设置自定义内容时自动回落到内置版。

### 数据与隐私

| 数据 | 位置 |
|---|---|
| 配置、会话库、资料库索引 | `%APPDATA%\MeowAi\MeowAi\` |
| 密钥 | 本地安全存储（DPAPI 加密） |
| 安装目录 | `%LOCALAPPDATA%\Programs\MeowAi` |

应用自身不提供账号、不上传资料库内容。发起对话时，只把当前消息、上下文片段和命中的资料片段发给你配置的模型服务商。卸载不会删除 `%APPDATA%` 下的用户数据，重装后仍可继续使用。

## 构建

准备 Qt 6.8.3 MinGW 套件与 MinGW 13.1，把两者的 `bin` 加入 `PATH`：

```powershell
$env:PATH = "C:\Qt\6.8.3\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;" + $env:PATH
```

配置与编译：

```powershell
cmake -S . -B build-mingw -G Ninja -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_PREFIX_PATH="C:/Qt/6.8.3/mingw_64"
cmake --build build-mingw --target MeowAi
```

运行：

```powershell
.\build-mingw\MeowAi.exe
```

无界面自检，退出码 0 表示 QML 加载正常：

```powershell
.\build-mingw\MeowAi.exe --smoke-test
```

需要 PDF 解析时：

```powershell
pwsh scripts/fetch-pdfium.ps1
```

ctest --test-dir build-mingw --output-on-failure

## 打包

1. 部署 Qt 运行时：

```powershell
windeployqt --release --qmldir ui --compiler-runtime <发布目录>\MeowAi.exe
```

2. 用 Inno Setup 6 编译 [scripts/MeowAi.iss](scripts/MeowAi.iss)。脚本按当前用户安装，不需要管理员权限，生成开始菜单与桌面快捷方式；版本号与 `CMakeLists.txt` 保持一致。

3. 发布目录内放安装包与两份手册：`MeowAi-Setup-<版本>.exe`、`USER_GUIDE.md`、`DEVELOPER_GUIDE.md`。手册随安装包一起提供，应用内“帮助”页可直接打开。

安装包与可执行文件均未做代码签名，分发时需告知用户 SmartScreen 提示的处理方式。

## 已知限制

- 安装包与可执行文件未签名。
- MinGW 版 Qt 不提供 WebEngine，界面内不嵌入浏览器内核。
- PDF 解析需要额外放置 PDFium，未随仓库分发。
- 仅提供 Windows 构建，macOS 与 Linux 未适配。
- 联网搜索入口已存在，检索结果质量取决于所接厂商能力，应用侧不做结果重排。
