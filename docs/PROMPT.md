## 你的角色
你是资深 Qt 6 架构师 / 全栈工程师。

## 本次任务：阶段一「底层架构搭建」
产出**可编译的框架骨架 + 接口定义**，不追求功能全量跑通。
技术栈：Qt 6（QML + C++17）+ CMake；适配 **Win / Android**；**预留 Web**（承载 iOS 用户）。

### 本阶段必须交付
1. **目录初始化**，按分层落地：`ui/ core/ providers/ storage/ platform/ resources/skills/`（另加 `tests/`）。
2. **可编译工程**：CMake 工程 + 最小可运行 QML 主窗口（能编译、能启动）。
3. **三个抽象接口**（只定义，不实现业务逻辑）：
   - `AiProvider` —— 屏蔽 OpenAI 与 Anthropic 协议差异；
   - `Skill` —— 扫描 `resources/skills/`、按 manifest 加载的规范；
   - `DocumentRetriever` —— **资料库检索接口，仅预留**（实现留后续，本阶段不得实现检索算法）。
4. **存储层骨架**：SQLite 访问封装 + 本地目录布局（`config / library / categories / backups / skills / assets`），Key 加密**接口占位**。
5. **平台适配层**：路径 / 网络 / 安装器差异抽象（Win、Android、Web 占位）。
6. **基础 CI + 单元测试框架**（为后续防崩溃打底）。

### 明确不做（本阶段）
- 不实现真实 AI 协议请求（只留接口 + 桩）。
- 不实现资料库检索算法。
- 不实现蓝奏云升级解析。
- 不做 Agent 式直接文件操作。
- iOS **不产出安装包**（由 Web 承载）。

## 硬性约束
- **分层**：UI(QML) 不写业务逻辑；网络全走 `providers/`；系统级操作只进 `platform/`。
- **数据口径**：仅**用户文件类数据**本地化；**不做本地模型、统一走 API**。
- 工程**必须编译通过**；含异常处理（空指针 / 断网 / 文件不存在），运行不崩溃。
- **省流**：每次只输出一个模块 / 一个类，确认后再继续；注释精简，不重复需求。
- 骨架需为**全部 11 项功能预留接入点**（清单见 `PROJECT_CHARTER.md` §2），但不在本阶段实现。

## 工作方式（重要）
1. **先给架构方案 + 完整文件清单（不写代码）**，我确认后再开始编码。
2. 编码逐模块进行；每完成一个模块**自测**，并说明如何验证。
3. 代码走 GitHub，分支按版本号命名，改动走 PR、可看 diff。

## 本阶段验收标准
- 至少 Win 端**可编译、可启动**的空壳应用。
- 三个抽象接口齐备，有清晰注释 / 文档。
- 目录结构与本地存储布局落地。
- 单测框架可运行、CI 可跑。
- 连续异常操作（空数据、断网等）**不闪退**。
