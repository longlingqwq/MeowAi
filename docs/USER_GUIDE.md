# MeowAi 用户手册

> 版本：v0.2.5（阶段二 · 资料库/RAG 已完成，待验收）
> 适用平台：Windows（桌面）；Android / Web 适配尚未完成
> 本手册面向**使用者**。开发相关内容见 [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md)。

---

## 1. MeowAi 是什么

一个**本地优先的 AI 助理客户端**：自己的文件留在自己电脑上，通过你配置的 AI 厂商接口来对话；可以把自己的一批资料（PDF、Excel、Word、PPT、图片等）放进"资料库"，让 AI **基于你的资料**回答，并列出引用来源。

它**不是**共享账号式的云服务：每人一份独立数据，无账号体系。

## 2. 第一次启动

### 2.1 启动
运行 `MeowAi.exe`。首次启动会自动创建本地数据目录（见 §7），界面为空是正常现象。

### 2.2 配置 AI 接入（必须先做）
在「对话」页顶部展开**接入卡**：

1. **选择厂商**：内置 OpenAI、DeepSeek、通义 Qwen、Kimi、智谱 GLM；也保留 Anthropic。
2. **选择模型**：从模型清单中选择，**不需要手写模型名**。
   - 想用清单里没有的模型：选择「自定义」→ 填写 API 地址（如 `https://xxx/v1`）与模型名。
   - 模型清单可点「拉取清单」从厂商动态获取（失败不影响内置清单）。
3. **填写 API Key** → 点「保存」→ 再点「验证」。
   - 验证结果有三种：**有效** / **无效（Key 错误）** / **无法验证（限流、超时、断网）**。
   - 「无法验证」不代表 Key 错了，稍后重试即可。
4. **思考强度**：对支持思考的模型可选 `关 / 低 / 中 / 高`；不支持的模型会提示"未声明思考档位"。
5. **高级参数**（可选）：可覆盖厂商原生参数（如 `reasoning_effort`、`budget_tokens`），留空即用档位映射。
6. **允许上传图片**（默认关闭）：只有打开后，带图片的请求才会真正发给厂商。

> Key 保存在本机加密保险库中（Windows 用 DPAPI），不会写入配置文件明文。

## 3. 日常对话

- **发送**：输入后用「发送」或回车；回答会**流式**出现。
- **中断**：生成中可点「中断」，本轮请求会被取消。
- **历史**：左侧列出会话，点「＋ 新对话」开新会话；**重启后历史仍在**（本地数据库）。
- **图片**：确认模型支持图片（接入卡显示"支持图片"）且已打开"允许上传图片"，即可附图发送。
- **联网搜索**：输入区附近可开启"联网"。开启后模型可自主发起搜索并抓取网页正文，回答会显示来源条数。
  - 内置搜索优先复用当前厂商能力；没有内置搜索的厂商可填写自定义搜索端点与密钥。

## 4. 资料库（核心功能）

资料库 = 你自己组织的"知识小库"。例如建一个「工程用」小库，把项目 PDF、施工规范、Excel 台账放进去；对话时挂载它，AI 就会基于这些资料回答。

### 4.1 创建小库
左侧导航进入「资料库」→ 输入名称 → 「＋ 新建小库」。
一个文件可以同时属于多个小库。

### 4.2 导入文件（两种方式）

| 方式 | 行为 | 适用 |
|---|---|---|
| **导入文件** / 拖拽文件到中栏 | **复制一份**到资料库目录，原文件不动 | 想固定留存、独立管理 |
| **关联文件夹** | **只建索引引用，不复制**；生成快照，之后可「重建快照」 | 文件本来就在某个项目文件夹里 |

支持的文本类：`txt / md / csv / json / PDF（需文本层） / docx / xlsx / pptx`
支持的图片类：`jpg / jpeg / png / webp / gif / bmp`

> 扫描版 PDF（纯图片）没有文本层，会显示"无文本层"，无法被检索。

### 4.3 让检索真正生效：配置两个服务

资料库用**向量检索**，需要两类服务（均走 API，可复用对话厂商的 Key）：

1. **embedding（文本向量）**——把文字变成可比较的"语义坐标"。
   - 若当前对话厂商不支持 embedding，请在本页单独选择一个支持 embedding 的厂商并填 Key。
   - 没配置时不报错：文件照常入库，但标记"待建向量"，检索降级为**关键词搜索**。
2. **视觉模型（图片描述）**——图片入库时先生成一段文字描述，描述参与检索。
   - 图片**不做本地解析**，由多模态模型生成描述；未配置时图片显示"待索引"。
   - 图片描述会把图片发给厂商，**必须单独同意**。

配置完成后点「重建索引」补齐。

### 4.4 状态说明

| 状态 | 含义 | 处理 |
|---|---|---|
| 已索引 | 可被检索 | — |
| 待建向量 | 已切分，缺 embedding | 配置 embedding 后重建 |
| 待索引 | 图片缺视觉模型 / 未同意 | 配置或同意后重建 |
| 无文本层 | PDF 是扫描件 | 需要 OCR（当前不支持） |
| 索引失败 | 文件损坏或格式异常 | 查看提示，必要时重新导入 |
| 内容已变化 | 关联文件夹里的源文件变了 | 点「重建快照」 |
| 不支持 | 视频等 | 当前不做视频 |

### 4.5 检索参数（可调）
在资料库页右侧可调整，改动立即生效：

- **Top-K**：最终注入对话的片段数量（默认 6）
- **每文件片段上限**：防止一个大文件占满名额（默认 2）
- **注入 token 预算**：每轮最多花多少上下文（默认 2000）
- **相似度阈值**：低于该值的片段丢弃（默认 0.30）
- **邻居扩展半径**：命中片段前后各带几段，避免语义被切断（默认 1）
- **关键词兜底**：embedding 不可用时自动改用关键词搜索（默认开）
- **切分尺寸 / 重叠**：影响片段粒度

### 4.6 在对话中使用
在「对话」页的挂载入口选择小库 → 发送问题。
- 资料库检索是**应用侧自动完成**的（不是让模型自己翻文件）。
- 回答末尾会列出 `[来源 N] 文件名（页码/工作表/行号）`，可据此核对。
- 顶部 chip 会显示：挂载了几个库、命中几个片段、占用多少 token、是否降级。
- 检索失败（限流/断网）**不会中断对话**，只提示降级。

### 4.7 删除安全
- **删除小库 / 解除关联只删索引与库内记录，绝不删除你的原始文件。**
- 关联文件夹方式只建引用，原文件夹不受任何影响。

### 4.8 库内搜索与成本
- 支持按关键词搜索库内文件内容（纯本地）。
- 成本预估区会显示"首次建向量大约多少 token / 多少钱、每次对话注入上限多少 token"，仅供参考。

> 首次启用资料库、首次挂载、图片外发时都会弹出**同意确认**：明确告知哪些内容会发给厂商。可随时在资料库页**撤回同意**——撤回后不再发出任何相关请求，已建本地索引保留。

## 5. 个性化

「个性化」页可设置：

- **主题**：当前内置「主题1（Nocturne 琥珀）」。切换后**立即生效并记住**，重启保持。
- **字体**：选用系统字体，或导入 `.ttf/.otf/.ttc` 字体文件；全局生效。
- **背景图**：png/jpg/webp/bmp/gif/svg，自动压暗保证文字可读。
- **头像**：显示在顶栏右上角，仅本机可见。
- **开屏动画**：选择本地视频（mp4/mov/m4v/webm/mkv/avi），可单独控制"启动时播放"和"播放音效"；可点「预览」。
- **恢复全部默认**：会清理已导入的字体、背景、头像与开屏视频。

## 7. 数据与隐私

### 7.1 数据都在哪里
默认在系统应用数据目录下（Windows 通常为 `%APPDATA%\MeowAi\MeowAi`，实际以应用为准）：

| 路径 | 内容 |
|---|---|
| `config.json` | 模型选择、检索参数、挂载的小库等**非敏感**配置 |
| `secure/` | API Key 的**加密**保险库 |
| `library/` | 导入时复制的资料库文件副本 |
| `assets/` | 自定义字体、背景、头像、开屏视频 |
| 数据库文件 | 会话历史、资料库索引、向量、引用记录 |

### 7.2 哪些内容会离开本机
- **对话内容**会发给你选择的模型厂商。
- **资料库**：原始文件留在本地，但**入库文本片段、图片描述、检索命中的片段**会发给所选厂商（embedding / 视觉 / 对话）。这是向量检索的必要条件。
- 联网搜索时，查询与网页抓取请求会发往搜索服务与目标网站。
- 以上均有明确的同意提示，可撤回。

### 7.3 不会发生的事
- 不会把 API Key 写入明文配置或日志。
- 不会因为删除小库而删除你的原始文件。
- 不会静默上传图片：未开启"允许上传图片"或未同意时，请求被拒绝。

## 8. 常见问题

**Q：填了 Key，验证显示"无法验证"？**
这是限流、超时或网络不通，不代表 Key 错误。检查网络/代理后重试。

**Q：对话报错 401/403？**
Key 无效或无权限，重新保存正确的 Key。

**Q：PDF 一直"无文本层"？**
它是扫描件（图片型 PDF），当前不做 OCR，无法检索。

**Q：导入文件后没反应？**
确认已选中小库；工具栏下方会显示导入结果（成功数量或失败原因）。也可以直接把文件拖进中栏。

**Q：文件已入库，但 AI 说"资料库中未找到足够依据"？**
检查：① 是否配置了 embedding（否则只做关键词）；② 是否挂载了小库；③ 状态是否为"已索引"；④ 是否调高了相似度阈值。

**Q：图片入库后一直"待索引"？**
缺少视觉模型配置或未同意图片外发。`.webp` 在部分 Qt 安装中缺少插件，也可能失败。

**Q：搜索/索引时界面卡一下？**
大 PDF/XLSX 的解析当前在界面线程执行，会有短暂卡顿，属已知限制。

**Q：AI 会改我的文件吗？**
不会。资料库当前是**只读**，"AI 修改文件 + 改前备份"尚未启用。

**Q：能搜索视频内容吗？**
不能。视频目前只占位，不做解析。

## 9. 当前版本的能力边界

已完成：AI 接入（多厂商/模型选择、思考档位、Key 校验、多模态）、安全存储、会话历史、主题系统、个性化、无边框标题栏、资料库（小库/导入/关联文件夹/文本与图片入库/向量与关键词检索/引用来源/成本预估/同意与撤回）、联网搜索。

尚未完成：
- Skill 系统（读取/注册/调用）
- 应用内升级（含蓝奏云）
- Android 与 Web 端适配
- 视频解析、网页批量抓取、AI 写回文件、rerank / 多轮检索 / 跨文件汇总
- 自动监视文件夹变化（当前为快照 + 手动重建）
