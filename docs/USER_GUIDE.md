> 版本：v0.2.6（Windows 桌面版）
> 适用人群：第一次使用 MeowAi 的普通用户
> 安装包：`MeowAi-Setup-0.2.6.exe`（DEVLOG 记录约 32.7 MB；仓库未保留产物，体积以实际文件为准）

## 1. 先认识一下 MeowAi

MeowAi 是装在 Windows 电脑上的 AI 对话客户端。它不内置大模型，也不在本机跑模型。回答能力来自你填写的厂商 API Key。程序负责界面、会话记录、资料库检索和隐私控制。

MeowAi 和网页版 AI 的主要区别有四点。第一，可以建资料库：把 PDF、Word、Excel、PPT、图片放进去，提问时程序会先从资料库里找相关内容，再交给模型回答。第二，数据放在本机：会话、资料库文件、索引和配置都保存在你的用户目录。第三，没有账号体系：每个 Windows 用户各用各的数据，发给朋友后互不影响。第四，资料外发需要你明确同意：首次启用资料库或挂载小库时会弹出同意说明，撤回同意后程序不再发送资料库内容。

MeowAi 不做这些事：不在本机运行大模型；不自动修改或删除你的原始文件；不解析视频；不对扫描版 PDF 做 OCR 文字识别；不提供应用内自动升级；目前只交付 Windows 桌面版，Android 与 Web 只有平台适配骨架，没有安装包。

## 2. 安装（第一次使用）

系统要求：Windows 10 或 Windows 11，64 位；能访问你选择的 AI 厂商接口；安装包所在磁盘至少有数百 MB 可用空间。

安装步骤。双击 `MeowAi-Setup-0.2.6.exe`。如果 Windows 弹出“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。安装向导是英文界面，一路点 Next 或 Install。安装程序按当前用户安装，不需要管理员权限。默认安装目录是 `C:\Users\<你的用户名>\AppData\Local\Programs\MeowAi`。安装完成后可以勾选立即启动，桌面和开始菜单会生成 MeowAi 快捷方式。

首次启动时，程序会在 `%APPDATA%\MeowAi\MeowAi\` 下创建配置、数据库、资料库、资源等目录。这个目录是本机数据目录，后文简称“数据目录”。

卸载。打开 Windows“设置 → 应用 → 已安装的应用 → MeowAi → 卸载”。卸载只删除程序文件，不删除数据目录，所以会话和资料库会保留。要彻底清理，先卸载，再手动删除数据目录，操作见第 8 节。

常见安装错误。安装包被安全软件拦截时，先确认文件来源，再把安装包加入信任名单后重试。提示没有写入权限时，确认选择的是当前用户目录，不要手工改到 `C:\Program Files`。双击后没有反应时，检查任务管理器里是否已有 MeowAi 进程，结束旧进程后再启动。

安装包与手册的发放方式。安装包只包含程序运行文件，不安装手册。发布时把 `MeowAi-Setup-0.2.6.exe`、`USER_GUIDE.md`、`DEVELOPER_GUIDE.md` 放在同一个发放目录里一起发给用户。DEVLOG 使用的目录名是 `产品/`，但当前仓库没有该目录，也没有 `dist/` 产物；需要按发布流程重新构建安装包。

## 3. 第一次打开：5 分钟完成配置

MeowAi 没有配置向导。第一次打开后，在“对话”页完成三步：选厂商、填 Key、选模型。入口都在对话页顶部的接入卡。

第一步，展开接入卡。程序启动后默认在“对话”页。页面顶部有一张接入卡，右侧按钮显示“配置”。点“配置”，卡片展开，出现厂商、模型、档位、密钥、安全等设置。再点“收起”可以折叠。卡片头部始终显示当前厂商、模型和密钥状态。

第二步，选厂商。在“厂商”下拉框里选择服务商。内置 7 项：OpenAI、DeepSeek、通义千问、月之暗面 Kimi、智谱 GLM、Anthropic、自定义（OpenAI 兼容）。选完后，“模型”下拉框会自动换成该厂商的模型清单。若清单为空，下拉框显示“该厂商无内置模型，可在下方手填模型名”。

第三步，选模型。在“模型”下拉框里选择模型。每个模型后面的小标签表示能力，例如“视觉”表示可以接收图片。下拉框宽度有限，长名称会省略，鼠标停留可以看到完整名称。若想使用厂商新发布的模型，点接入卡里的“拉取清单”，程序会请求厂商的模型列表；请求失败时保留内置清单，不会清空。

第四步，填 API Key。在“密钥”输入框里粘贴 Key。输入框是密码样式，内容不会明文显示。点“保存”。保存成功后输入框清空，右侧状态变成“密钥已就绪（未校验）”。点“验证”可以主动检查 Key。验证需要几秒，期间状态显示“校验中…”。验证结果有四种：密钥有效、密钥无效、无法验证、未配置密钥。点“清除”可以删除已保存的 Key。

Key 只保存在本机加密保险库，不写入 `config.json`。Windows 使用 DPAPI 用户级加密，文件位于数据目录的 `secure/` 下。换 Windows 账户或换电脑后，旧密文通常无法解密，需要重新填 Key。

第五步，发第一句话。在底部输入框输入内容，按回车或点“发送”。生成期间输入框显示“正在生成…”，发送按钮禁用，旁边出现“中断”。点“中断”会停止本次请求，已经生成的内容保留。请求失败时，接入卡下方会出现红色错误横幅，横幅里写原因。

常见配置错误。厂商选“自定义（OpenAI 兼容）”时，必须同时填写“API 链接”和“模型名”，否则发送和验证都会被拒绝。API 链接要填到 `/v1` 这一级，例如 `https://your-gateway.example/v1`。状态显示“未配置密钥”时，先保存 Key，再发送。状态显示“密钥无效”时，检查 Key 是否复制完整、是否属于当前厂商。状态显示“无法验证”时，通常是限流、超时或断网，不代表 Key 一定错误，稍后重试即可。状态显示“本平台不支持加密存储”时，当前平台无法保存 Key；Windows 桌面版不会出现这个状态。

## 4. 日常对话

对话页分四块。左侧是会话列表，顶部有“＋ 新对话”。中间上方是接入卡，下方是消息流。底部是输入条，从左到右依次是输入框、“智能联网”开关、“资料库”开关、“发送”按钮；生成期间还会出现“中断”。输入条下面一行是“附图”路径框和图片上传确认提示。

新建会话。点左侧“＋ 新对话”。当前消息流清空，出现新的会话。发送第一条消息后，会话标题自动取这条消息的开头部分。

切换会话。在左侧会话列表点任意一条。消息流切换到该会话。程序只把最近 20 条消息作为有界历史发给模型，避免上下文无限增长。

删除会话。把鼠标移到会话条目上，右侧出现 ×。点 × 会立即删除该会话及其全部消息，没有二次确认，也不能恢复。删除前请确认不需要保留。

发送消息。输入内容后按回车，或点“发送”。输入框是单行输入，回车即发送，不能用回车换行。消息发送后，用户消息显示在右侧，助手回复显示在左侧。生成期间助手气泡带呼吸竖线。成功后竖线停止，消息状态变为完成。

中断生成。生成期间点“中断”。程序会真正取消在途网络请求。已生成的部分保留，但这一条不会再继续生成。中断后可以重新发送。

错误横幅。请求失败时，接入卡下方显示红色横幅。横幅优先显示网络或密钥错误，其次显示会话历史错误。常见原因包括 Key 无效、余额不足、限流、超时、断网、模型名不存在。处理完原因后重新发送，横幅会被新的结果替换。

换模型和档位。页面底部有一个“当前”胶囊，显示当前模型、档位、视觉能力和高级参数摘要。鼠标停留在胶囊上约 1 秒，或单击、长按胶囊，会打开“模型与档位”二级菜单。菜单里可以点模型行切换模型。模型行内的档位胶囊可以直接选档位，档位含义是“关、低、中、高”，具体支持哪些档位由厂商和模型决定。菜单底部是“高级原生参数”，可以填一段 JSON，例如 `{"reasoning_effort":"high"}`。点“应用”后，高级参数覆盖档位映射；点“重置”恢复档位映射。JSON 不是对象或解析失败时，菜单内会显示错误，不会应用。

高级参数的使用边界。高级参数会原样透传到厂商请求体，程序会跳过 `model`、`messages`、`stream`、`system` 等保留字段。不熟悉厂商字段时不要填写。填错可能导致请求被厂商拒绝。

附图。只有在当前模型声明“视觉”能力时，附图入口才可用。把图片的完整路径填进“附图”输入框，再发送。图片不会自动上传：必须先打开接入卡里的“安全”开关，文字是“允许把图片上传给厂商（默认关闭；关闭时带图请求会被拒绝）”。开关关闭时，即使填了路径，请求也会被拒绝，输入条右侧提示“未确认：该图片不会被上传”。开关打开后提示变为“已确认：该图片会被上传”。当前模型没有视觉能力时，附图框禁用，提示“该模型未声明视觉能力，附图入口已关闭”。

智能联网。输入条上的“智能联网”开关控制本轮是否允许模型自行上网。开启后，联网搜索作为工具交给模型，模型判断需要时才搜索；不需要就不联网。开关关闭时与普通对话完全一致。开关打开但当前厂商没有可用搜索配置时，提问会自动降级为普通对话，并在错误横幅里写明原因。

联网搜索的配置入口。点底部“当前”胶囊打开“模型与档位”菜单，找到“联网搜索”一行。该行显示状态和来源类型：DeepSeek 显示“内置源 · 零配置”，其他厂商显示“自定义源”。点“配置…”打开“联网搜索”弹层。弹层里可以看到总开关、搜索源说明、端点和密钥。DeepSeek 使用内置搜索，复用已保存的 DeepSeek Key，不需要填端点。其他厂商需要填写一个返回 JSON 的搜索端点，端点里可以用 `{query}` 占位；没有占位时程序自动追加 `?q=`。自定义源还需要保存搜索密钥。端点或密钥缺失时，状态显示“未就绪”。

联网结果。联网成功后，回答上方出现“已联网 · N 条来源”和来源标题，最多展示前 3 条。程序先检索，再抓取前 2 条网页正文，拼成上下文交给模型。单页抓取失败只跳过该页，不中断整轮。检索失败、超时、断网、401、403、429 都会降级为普通对话并给出提示。

资料库开关。输入条上的“资料库”开关用于选择本轮参与检索的小库。点开后出现“挂载到对话的小库”列表，每个小库右侧有开关。第一次挂载时，如果还没有同意资料库外发，程序会先弹出同意说明；同意后才挂载。挂载状态会记住，重启后保持。挂载只影响本轮上下文，不修改库内容。

## 5. 资料库：把自己的文件变成 AI 的参考书

资料库页在左侧导航第三项。页面分三栏：左栏是小库列表，中栏是文件、文件夹快照和导入操作，右栏是检索与隐私、检索参数、参考资料模式、embedding、图片描述、成本预估和库内搜索。

启用与同意。右栏最上方是“检索与隐私”。未同意时显示“尚未同意：文件可本地入库，但不会建立向量、不会发给任何模型”。点“同意并启用”，弹出同意说明。说明里列出哪些内容会离开本机、如何撤回。点“同意并启用”后，按钮变为“启用资料库/停用资料库”和“撤回同意”。点“暂不启用”会关闭弹层，资料库保持未启用，文件仍可本地入库，但不建向量、不做图片描述。撤回后，程序立即关闭挂载与启用，索引器和图片描述服务同步停止外发；已经建好的本地索引保留。点“停用资料库”只停止使用，不撤回同意。

新建小库。在左栏“新建小库名称”输入名称，点“＋ 新建小库”。列表出现新小库，文件数为 0。点小库条目切换当前小库。若没有选中小库就导入文件，程序会自动使用“默认资料库”，没有则自动创建。

删除小库。把鼠标移到小库条目，点右侧 ×。下方出现红色确认条“删除小库只删索引，不删原文件”。点“确认删除”删除；点“取消”返回。删除小库不会删除你磁盘上的原始文件。

导入文件。在中栏点“导入文件”，打开系统文件选择框，可以多选。选中后点确定，程序把文件复制一份到数据目录的资料库目录，原文件保持不动。也可以直接把文件拖到中栏，出现琥珀色遮罩和“松开即可导入到「当前小库」”后松开。拖拽只接受文件，拖文件夹不会自动转为关联文件夹。导入结果显示在中栏工具栏下方，包含目标小库名和成功数量；部分失败时会同时给出成功数和失败原因。

支持的文件类型。文本类：`txt`、`md`、`markdown`、`csv`、`tsv`、`json`、`log`、`pdf`、`docx`、`xlsx`、`pptx`。图片类：`jpg`、`jpeg`、`png`、`webp`、`gif`、`bmp`。视频类只登记、不解析，包括 `mp4`、`mov`、`mkv`、`avi`、`webm`、`m4v`，导入后状态为“不支持”。其他扩展名会被拒绝。

关联文件夹。在中栏点“关联文件夹”，选择目录。程序在关联时做一次快照，把目录中的支持文件纳入索引，不会实时监视目录。目录上方显示路径、文件数和快照时间。源目录后来新增或修改文件时，点“重建快照”同步。点“解除关联”只删除关联和索引，不删除原目录里的文件。

文件状态。列表里每个文件有一个状态标签，含义如下。

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 已索引 | 文本已切分并完成向量化；图片已生成描述并入库 | 可以直接挂载使用 |
| 待建向量 | 文本片段已入库，但缺少 embedding 配置或 Key，尚未生成向量 | 配置 embedding 后点“重建”或“重建索引” |
| 待索引 | 尚未处理，或图片缺少视觉模型/同意 | 配置视觉模型并同意外发，或点“重建” |
| 无文本层 | PDF 没有可提取文字，或自行构建时未放置 PDFium | 换有文本层的文件；扫描件需要 OCR，当前不支持 |
| 索引失败 | 解析或请求失败 | 看文件行里的错误说明，修正后点“重建” |
| 内容已变化 | 源文件或快照内容与索引不一致 | 点“重建” |
| 不支持 | 视频或未登记类型 | 当前版本不解析 |

自动索引。文件导入后会自动进入索引队列，同一时刻只处理一个文件。文本链路是：本地解析 → 切分 → 入库 → 生成向量。图片链路是：本地转码 → 视觉模型生成描述 → 与文本同路径入库。可执行文件操作的按钮有“导入文件”“关联文件夹”“重建索引”；文件行内还有“重建”和“移除”。点“重建索引”会重建当前小库全部文件。点文件行的“移除”会立即删除该文件在资料库里的副本和索引，没有二次确认，不删除你导入前的原始文件。

缺少前置条件时的提示。导入图片但没配视觉模型时，中栏上方提示“N 张图片已入库，但缺少视觉模型，暂时无法生成描述与索引”，旁边有“去配置”，点击跳到右栏图片描述区。缺少 embedding 时也有同类提示和“去配置”。

embedding 配置。右栏“内容向量化（embedding）”区先选厂商，再在“embedding 模型名”里填模型名，点“保存 embedding 配置”。可选厂商由厂商目录中带 embedding 能力的条目决定，当前是 OpenAI、通义千问、智谱 GLM。可以单独填写 embedding API Key，点“保存 embedding Key”；输入框留空时，如果 embedding 厂商与对话厂商相同，程序会复用对话 Key。换厂商后不复用，需要单独保存 Key。配置完成后，之前处于“待建向量”的文件需要点“重建索引”补齐。

图片描述配置。右栏“图片描述（caption）”区先选视觉模型厂商，再在“视觉模型名”里填模型名，点“保存图片描述配置”。可以单独填写视觉 API Key，点“保存图片描述 Key”；留空时，厂商与对话厂商相同则复用对话 Key。图片描述需要资料库同意。未同意时图片停在“待索引”，程序连本地转码都不做。

检索参数。右栏参数在编辑完成后立即保存，重启后保持。含义和默认值如下。

| 参数 | 含义 | 默认值 | 可填范围 |
| --- | --- | --- | --- |
| Top-K | 最终注入的片段数 | 6 | 1–30 |
| 每文件片段上限 | 单个文件最多贡献几个片段，防止大文件占满 Top-K | 2 | 1–10 |
| 注入 token 预算 | 经过检索、邻居扩展后用于注入的 token 上限 | 2000 | 200–20000 |
| 相似度阈值 | 低于该分数的片段不参与 | 0.30 | 0–1 |
| 邻居扩展半径 | 命中片段前后各带几段 | 1 | 0–3 |
| 关键词兜底 | embedding 不可用时用本地关键词检索 | 开启 | 开/关 |
| 切分尺寸 | 每个片段的字符数 | 700 | 200–4000 |
| 片段重叠 | 相邻片段重叠字符数 | 120 | 0 到切分尺寸的一半（默认最多 350） |
| 单文件预算 | 参考资料模式下单个文件最多注入多少 token | 20000 | 1000–200000 |
| 全局预算 | 所有相关文件合计注入上限 | 100000 | 1000–500000 |
| 回答预留 | 给模型生成回答预留的 token | 2000 | 200–32000 |
| 未知窗口估算值 | 模型没有提供上下文窗口时使用的窗口大小 | 32768 | 2000–4000000 |
| 文件聚合权重 | 文件打分 = 最高片段分 + 命中数 × 权重 | 0.05 | 固定值，界面不提供输入 |

成本预估。右栏“成本预估（参考）”显示当前小库的文本 token、图片张数、首次建向量金额、图片描述金额和每次对话注入上限。金额来自内置价格表，按厂商和模型精确匹配。未收录的模型显示“—”并提示只估算 token。价格表是参考值，不联网更新，实际以厂商账单为准。

库内搜索。右栏“库内搜索（本地关键词）”输入关键词后回车。结果显示文件名、定位和摘要。清空输入框会清空结果。搜索只查本地索引，不联网。

参考资料模式。资料库挂载后，每轮提问会先做文件级召回，再按“全文 → 章节 → 片段”三级决定注入方式。文件足够小且预算充足时注入全文。文件较大但有章节结构时注入相关章节。再不行才注入片段。回答上方会显示“资料库 · N 个小库”“N 个片段 · N token”，以及来源和注入标签。注入标签会写明文件名、注入级别、token 数；被截断时标“已截断”，章节是按近似结构推断时标“（近似章节）”。没有命中文件时，程序不注入任何资料库提示词，模型按普通对话回答。

预算与上下文窗口。程序先算可用预算：模型上下文窗口减去历史占用，再减去回答预留。结果再与单文件预算、全局预算逐级取最小值。模型窗口优先取厂商模型清单里的窗口字段；厂商不返回时用 `providers.json` 内置值；都没有时用“未知窗口估算值”，默认 32768。预算超限时只截断，不报错，不会因为上下文过长触发 400。

章节识别。docx 按标题样式 `Heading1`–`6` 或大纲级别分章；Markdown 按 `#` 到 `######` 分章；xlsx 按工作表、pptx 按幻灯片、PDF 按页近似分章。docx 使用自定义样式名且没有大纲级别时，可能识别不到章节，程序退回片段模式。标题本身不进入注入正文。

隐私边界。资料库文件先在本机解析。只有同意后，文本片段才会发给 embedding 厂商，图片才会发给视觉模型厂商。撤回同意后，程序不再发送任何资料库内容。日志和错误信息不打印正文、不打印 Key、不打印请求体。

## 6. 个性化

个性化页在左侧导航第二项。页面从上到下是主题、字体、背景、头像、开屏动画、帮助与关于、重置。所有设置写入 `config.json` 的 `personalization` 与 `theme` 段，导入的文件复制到数据目录的 `assets/` 下。

主题。页面顶部列出内置主题按钮：Nocturne 琥珀、Daylight 浅蓝。当前主题按钮高亮。点另一个主题会立即换色，选择会记住，重启后保持。主题只替换设计令牌，不改变功能。主题文件缺失或令牌不完整时，页面显示错误，程序保留当前主题。

字体。在“字体”区选择系统字体，点“使用此字体”。字体全局生效，包括对话框和列表。点“导入字体文件…”，选择 `.ttf`、`.otf`、`.ttc` 文件，单个文件上限 20 MB；程序把字体复制到 `assets/fonts` 并注册。点“恢复默认”回到系统默认字体。导入失败时页面底部显示错误。文件不是有效字体、文件为空或无权读取时都会失败。

背景。在“背景”区点“选择背景图…”，支持 `png`、`jpg`、`jpeg`、`webp`、`bmp`、`gif`、`svg`，单个文件上限 20 MB。选中后背景立即应用，并自动压暗以保证文字可读。点“清除背景”恢复默认。文件不存在、格式不支持或超过 20 MB 时失败，页面显示错误。

头像。在“头像”区点“选择头像…”，支持格式和 20 MB 上限与背景相同。头像显示在顶栏右上角。点“清除头像”恢复默认的“猫”字徽记。

开屏动画。在“开屏动画”区点“选择视频…”，支持 `mp4`、`mov`、`m4v`、`webm`、`mkv`、`avi`，单个文件上限 200 MB。选中后可以用“预览”立即播放。打开“启动时播放”后，下次启动会播放；播放结束或点“跳过”进入主界面。“播放音效”控制视频自带音轨，只有“启动时播放”打开时才可用。点“清除”删除自定义视频。视频无法解码时，播放层会结束并进入主界面，不会卡住。

帮助。页面底部“帮助”区显示开发者 Longling 和联系方式 3086865618@qq.com。点“帮助”按钮打开弹层，里面有快速上手步骤和手册位置说明。点“关闭”或按 Esc 关闭。

重置。页面底部“恢复全部默认”是危险色按钮。点下去立即恢复全部默认外观，并删除已导入的字体、背景、头像和开屏视频文件。这个操作没有二次确认，执行前请确认。

常见错误。字体列表为空时，系统字体枚举失败，重启程序后重试。背景或头像设置了但界面没变化时，确认文件仍在数据目录的 `assets/` 下；文件被手工删除后，程序会回落默认。开屏视频没有声音时，检查“播放音效”开关和系统音量；视频本身没有音轨时也不会有声音。

## 7. 窗口操作

Windows 桌面版使用无边框自绘标题栏。窗口顶部是自绘标题栏，左侧是品牌区，中间是页面标题，右侧是最小化、最大化/还原、关闭三个按钮。

移动窗口。按住标题栏空白处拖动。双击标题栏空白处在最大化和还原之间切换。

缩放窗口。把鼠标移到窗口边缘或四角，出现缩放指针后拖动。边缘命中宽度为 6 像素。窗口最大化时使用系统工作区，不会盖住任务栏。

按钮操作。最小化按钮把窗口收进任务栏。最大化/还原按钮切换窗口状态。关闭按钮退出程序。关闭前不会弹出“是否保存”提示，会话和资料库已经实时落库。

小屏幕与多显示器。程序启动时按可用屏幕收缩初始尺寸，并把窗口位置收回到屏幕内。可用宽度小于 1200 或高度小于 820 时自动最大化。切换显示器或远程桌面后，窗口会重新收回屏幕。如果窗口仍然超出屏幕，先按最大化按钮，再还原。

窗口拖不动或关不掉时的处理。先用 Alt+F4 关闭。若仍无响应，在任务管理器结束 MeowAi 进程。下次启动后，程序会重新把窗口放到屏幕内。这个问题属于窗口管理异常，不是数据损坏；会话和资料库不会因此丢失。

## 8. 数据与隐私

数据目录。Windows 下是 `%APPDATA%\MeowAi\MeowAi\`，也就是 `C:\Users\<你的用户名>\AppData\Roaming\MeowAi\MeowAi\`。目录里有这些内容。

| 路径 | 内容 |
| --- | --- |
| `config.json` | AI 厂商/模型选择、资料库参数、联网配置、主题、个性化设置；不含任何 Key |
| `metadata.db` | SQLite 数据库，保存会话、消息、资料库元数据、片段、向量和章节 |
| `secure/` | Key 保险库，Windows 下由 DPAPI 加密 |
| `library/` | 资料库文件副本和小库目录 |
| `assets/` | 导入的字体、背景、头像、开屏视频 |
| `categories/` | 预留的分类文件目录，当前没有实际写入 |
| `backups/` | 预留的修改前备份目录，当前没有实际写入 |
| `skills/` | 预留的技能目录，当前空置；技能扫描读取内置 `resources/skills`，不参与对话 |

会离开本机的内容。你发送的提问和程序附带的有界历史会发给你选择的对话厂商。挂载资料库后，检索命中的文件内容会发给对话厂商；文本向量化时，片段会发给 embedding 厂商；图片描述时，图片会发给视觉模型厂商。开启智能联网后，检索词会发给搜索服务，网页正文会进入对话上下文。以上外发都以你配置的厂商和同意状态为前提。

不会发生的事。程序没有账号系统，不上传会话到自己的服务器，不做使用统计。Key 不会明文写入 `config.json`，不会写进日志，不会放进 URL。资料库未同意时，程序不会建立向量，也不会把图片发给视觉模型。资料库文件先在本机解析。删除小库、解除关联、移除文件都不会删除你导入前的原始文件。程序不会自动修改原始文件，也不会自动删除它们。

备份。先完全退出 MeowAi。复制整个数据目录到备份位置。恢复时，把备份目录复制回 `%APPDATA%\MeowAi\MeowAi\`。不要只复制 `metadata.db`，因为资料库文件和向量在 `library/` 与数据库里，必须一起复制。程序运行中复制可能拿到不一致的数据库快照，所以要先退出。

迁移到另一台电脑。复制整个数据目录到新电脑的同一位置。会话、资料库、索引和个性化资源可以迁移。Key 由 Windows DPAPI 加密，换电脑或换 Windows 账户后通常无法解密，需要在新电脑上重新填写 Key。资料库索引可以继续使用；换 embedding 厂商或模型后需要重建向量。

彻底清理。先卸载程序，再删除 `%APPDATA%\MeowAi\MeowAi\`。删除前确认不需要保留会话和资料库。删除后无法恢复。

## 9. 常见问题

问：密钥输入框是灰色，保存按钮点不了。答：当前平台不支持加密存储。Windows 桌面版使用 DPAPI，正常可用。若出现这个状态，确认运行的是 Windows 安装包里的 `MeowAi.exe`，不要在 Web 或未实现的平台上使用。

问：保存 Key 时提示失败。答：检查数据目录是否可写、磁盘是否已满、安全软件是否拦截了 `secure/` 目录。修复后重新保存。

问：状态显示“密钥已就绪（未校验）”，能直接发消息吗。答：能。这个状态表示 Key 已保存但还没主动验证。发送时如果 Key 有问题，会通过错误横幅返回。

问：状态显示“密钥无效”。答：检查 Key 是否复制完整、是否属于当前厂商、是否已被厂商停用。换一个 Key 或换厂商后重试。

问：状态显示“无法验证”。答：常见原因是限流、超时、断网或厂商服务异常。这不等于 Key 无效。等几分钟再点“验证”。

问：发送后提示 401 或 403。答：鉴权失败。重新保存 Key，确认厂商和模型匹配。自定义厂商还要确认 API 链接正确。

问：发送后提示 429。答：触发厂商限流或余额不足。降低发送频率，或到厂商控制台检查额度和账单。

问：发送后一直转圈，最后超时。答：检查网络和厂商服务状态。点“中断”后重试。代理软件、防火墙和公司网络可能拦截请求。

问：提示“自定义厂商需要填写 API 链接和模型名”。答：在接入卡里把“API 链接”和“模型名”都填全。链接填到 `/v1` 这一级。

问：附图入口是灰的。答：当前模型没有声明视觉能力。换一个带“视觉”标签的模型，例如 DeepSeek Flash、GPT-4o 或通义千问 Qwen3 VL Plus。

问：填了图片路径，发送后图片没有上传。答：接入卡“安全”开关没有打开。打开“允许把图片上传给厂商”后再发送。开关默认关闭，这是有意的隐私保护。

问：图片导入后一直“待索引”。答：没有配置视觉模型，或还没有同意资料库外发。到右栏“图片描述”配置厂商和模型，保存 Key，再点“重建索引”。`webp` 图片还可能因为缺少 Qt 图片插件而失败，必要时转成 `png` 或 `jpg`。

问：文本文件显示“待建向量”。答：没有配置 embedding，或 embedding Key 不可用。配置 embedding 后点“重建索引”。如果只想用关键词检索，可以保持“关键词兜底”开启。

问：PDF 显示“无文本层”。答：可能是扫描件，当前不做 OCR；也可能是构建时没有放置 PDFium。仓库当前没有 `third_party/pdfium`，直接从源码构建时 PDF 会走这个分支。自行构建时运行 `pwsh scripts/fetch-pdfium.ps1`，再重新构建。DEVLOG 记录发布安装包内置 PDFium，但仓库没有保留安装包，无法直接核对。

问：导入大 PDF 或大 Excel 时界面卡住。答：当前解析和索引在 UI 线程同步执行，大文件会短暂卡顿。等处理完成，不要重复点击。后续版本会把解析移到工作线程。

问：删除小库后原文件还在吗。答：在。删除小库只删资料库副本和索引。解除文件夹关联也一样，不删除源目录文件。

问：文件行的“移除”会删除我的原文件吗。答：不会。它删除资料库里的副本和索引。你导入前的原文件不受影响。

问：智能联网打开了，但没有联网。答：当前厂商可能没有内置搜索，且没有配置自定义端点。DeepSeek 可以零配置使用。其他厂商需要在“模型与档位 → 联网搜索 → 配置…”里填端点和密钥。配置不可用时，程序会降级为普通对话并给出提示。

问：联网提示“未就绪”。答：检查端点和密钥。端点必须以 `http://` 或 `https://` 开头，并返回 JSON。DeepSeek 内置源检查是否已保存 DeepSeek Key。

问：资料库挂载了，但回答没有引用文件。答：可能没有命中相关内容，或相似度低于阈值，或预算被截断。看回答上方的“来源”和“注入”标签。可以降低相似度阈值、提高 Top-K 或提高预算。没有命中时程序不会硬塞资料。

问：回答里的引用位置不准。答：定位按页、工作表、幻灯片或片段序号生成。章节是近似推断时，定位可能只到文件级。以标签里的文件名和定位为准。

问：换主题后有些地方颜色不对。答：主题文件必须包含完整令牌集。缺令牌时页面会报错。内置两个主题不会出现这个问题；自定义主题需要补齐全部令牌。

问：开屏视频没有声音。答：检查“播放音效”是否打开、系统音量是否静音、视频是否自带音轨。只有“启动时播放”打开时音效开关才可用。

问：能不能自动升级。答：当前版本没有应用内升级。`UpdateManager` 只有骨架，没有更新源和下载入口。升级时覆盖安装新版本安装包，数据目录会保留。

问：Android 或网页版在哪里下载。答：当前只交付 Windows 桌面版。仓库里有 Android 和 Web 的平台适配代码，但没有构建产物，也没有可用入口。

问：Skill 能用来做什么。答：当前版本只扫描内置示例技能，不把技能接入对话。界面上没有技能入口，也不会调用技能。不要向用户承诺技能能力。
