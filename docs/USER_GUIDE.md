> 版本：v0.2.8（Windows 桌面版）
> 适用人群：第一次使用 MeowAi 的普通用户
> 安装包：`MeowAi-Setup-0.2.8.exe`
> 开发者：Longling　联系方式：3086865618@qq.com
> 口径说明：本手册按仓库 v0.2.8 分支的代码核对。未实现的功能会直接写明“尚未提供”。

## 1. 先认识一下 MeowAi

MeowAi 是装在 Windows 电脑上的 AI 对话客户端。它不内置大模型，也不在本机跑模型。回答能力来自你填写的厂商 API Key。程序负责界面、会话记录、资料库检索和隐私控制。

MeowAi 和网页版 AI 的主要区别有六点。第一，可以建资料库：把 PDF、Word、Excel、PPT、图片放进去，提问时程序会先从资料库里找相关内容，再交给模型回答。第二，数据放在本机：会话、资料库文件、索引和配置都保存在你的用户目录。第三，没有账号体系：每个 Windows 用户各用各的数据，发给朋友后互不影响。第四，资料外发需要你明确同意：首次启用资料库或挂载小库时会弹出同意说明，撤回同意后程序不再发送资料库内容。第五，角色卡：把「模型 + 思考档位 + 人格提示词」打包成一个卡，点一下整套切换，不用每次手动配。第六，技能仓库：装一个小技能包，命中触发词时自动往对话里补一段专门的操作指引，也可以关掉自动、改成手动挑。

MeowAi 不做这些事：不在本机运行大模型；不自动修改或删除你的原始文件；不解析视频；不对扫描版 PDF 做 OCR 文字识别；不提供应用内自动升级；目前只交付 Windows 桌面版，Android 与 Web 只有平台适配骨架，没有安装包。

当前版本新增的界面能力：左侧可折叠导航栏、会话列表、角色卡区块（一键套用模型 / 档位 / 人格提示词）、技能仓库（导入技能包、按触发词自动注入或手动选择）、顶部模型胶囊与配置面板、资料库右侧配置抽屉、按主题播放的内置开屏动画、头像裁剪、消息 Token 与耗时展示、回答复制与重新生成。

## 2. 安装（第一次使用）

安装包只支持 64 位 Windows。系统要求 Windows 10 或 Windows 11。

安装步骤：

1. 双击 `MeowAi-Setup-0.2.8.exe`。
2. 安装向导的按钮和主要文案是英文；桌面快捷方式任务的描述是中文。点 `Next`。
3. 选择安装位置。默认是 `C:\Users\<你的用户名>\AppData\Local\Programs\MeowAi`。建议保持默认。
4. 选择是否创建桌面快捷方式。默认勾选。
5. 点 `Install`。安装过程不需要管理员权限。
6. 安装完成后点 `Finish`。程序会自动启动。

安装行为说明：

- 安装范围是当前 Windows 用户，不会写入 `Program Files`，也不会给其他用户安装。
- 开始菜单会创建 `MeowAi` 快捷方式。
- 安装包附带本手册，位于安装目录的 `docs/USER_GUIDE.md`，可在「个性化 → 帮助 → 打开用户手册」直接打开。发放目录同时提供开发手册。
- 安装程序没有中文界面。这是当前版本的已知限制。

卸载步骤：

1. 打开 Windows“设置 → 应用 → 已安装的应用”。
2. 找到 `MeowAi`，点“卸载”。
3. 卸载程序只删除安装目录。

卸载不会删除 `%APPDATA%\MeowAi\MeowAi` 下的会话、资料库、密钥和配置。需要彻底清理时，手动删除这个目录。删除前确认不再需要历史会话和资料库索引。

安装失败时按顺序检查：

1. 确认安装包完整。文件大小应在 33 MB 左右。
2. 确认当前用户对 `%LOCALAPPDATA%\Programs` 有写权限。
3. 关闭正在运行的 MeowAi，再重新安装。
4. 仍然失败时，把安装向导的完整报错文字发给开发者。

## 3. 第一次打开：5 分钟完成配置

MeowAi 没有配置向导。第一次打开后，在“对话”页完成三步：选厂商、填 Key、选模型。入口都在页面顶部的模型胶囊和“配置”按钮。

启动时会先播放开屏动画。内置开屏按当前主题显示品牌动画，约 3.5 秒。点右下角“跳过”可以直接进入主界面。第二次启动仍会播放，除非在“个性化”里关闭“启动时播放”。

第一步，展开配置面板。程序启动后默认在“对话”页。页面顶部左侧显示“对话”标题，右侧有模型胶囊和“配置”胶囊。点“配置”，页面顶部展开接入配置面板。再点“配置”可以收起。切换到“个性化”或“资料库”页时，面板会自动关闭。

第二步，选择厂商。在“厂商”下拉框里选择服务商。内置 7 个入口：OpenAI、DeepSeek、通义千问、Kimi、智谱 GLM、Anthropic、自定义。

第三步，填写 API Key。在“密钥”输入框里粘贴 Key，点“保存”。保存成功后输入框清空。Key 只写入本机加密保险库，不写进 `config.json`。

第四步，验证 Key。点“验证”。程序会向厂商发一次最小请求。验证期间按钮显示“验证中…”。结果有三种：已验证、Key 无效、无法验证。收到 401 或 403 时判定为 Key 无效。收到 429、断网或超时时判定为无法验证，不代表 Key 错误。

第五步，选择模型。点顶部模型胶囊，打开模型菜单。菜单打开的三种方式：鼠标悬停约 1 秒、单击、长按。在菜单里点模型行即可切换，菜单保持打开。也可以展开“配置”面板，在“模型”下拉框里选择。

如果模型列表为空，点“拉取清单”。程序会向厂商请求模型列表。拉取失败时保留内置清单，并在面板里显示失败原因。没有网络或 Key 未保存时，拉取会失败。

第六步，按需设置档位。模型菜单里有“关 / 低 / 中 / 高”档位。点档位会切换到该模型并应用档位，然后关闭菜单。档位含义由厂商参数映射决定，不同模型支持的档位可能不同。

第七步，按需填写高级原生参数。模型菜单底部有“高级原生参数”输入区，内容是一段 JSON。填写后点“应用”，会覆盖档位映射。点任意档位会解除高级覆盖。JSON 格式错误时菜单显示“JSON 解析失败：…”，不会发送请求。不确定时不要填写。

第八步，确认安全开关。配置面板里有“安全”开关，文案是“允许把图片上传给厂商（默认关闭；关闭时带图请求会被拒绝）”。只发文字时保持关闭即可。需要发图片时再打开。

使用自定义厂商时，配置面板会多出“API 链接”和“模型名”两行。API 链接填 OpenAI 兼容网关的完整地址，例如 `https://your-gateway.example/v1`。模型名按网关要求填写。自定义厂商只按 OpenAI 兼容协议发送 `/chat/completions` 请求，不支持 Anthropic 协议。链接和模型名都填全后才会发请求。

常见配置错误：

- 选了厂商但没填 Key，发送时提示“未配置密钥”。回到配置面板保存 Key。
- Key 填错，验证提示“Key 无效”。检查是否复制了多余空格，或 Key 是否已过期。
- 自定义链接少了 `/v1`，请求返回 404。按网关文档补全路径。
- 模型名不在厂商清单里，请求返回 400 或 404。改用“拉取清单”得到的名称。
- 公司网络拦截请求，验证提示“无法验证”。换网络或配置代理后再试。

## 4. 日常对话

新建对话。左侧导航栏展开时，顶部有“＋ 新对话”。点它创建一条空会话。侧栏收起时，先点侧栏顶部的展开按钮。

切换对话。左侧“对话”导航项有展开箭头。展开后显示会话列表。会话标题由第一条用户消息自动生成。点会话条目即可切换。

删除对话。会话条目右侧有 `×`。点它立即删除，没有二次确认。删除后无法恢复。误删只能重新提问，历史不会回来。

发送消息。在底部输入框输入文字。输入框是单行。按 Enter 发送。也可以点“发送”。生成过程中输入框禁用，按钮变为“中断”。点“中断”停止本轮生成，已生成的部分内容会保留。

附图。只有当前模型声明支持视觉时才可用。在输入框下方的“附图”输入框填写本地图片路径，或在文件选择器里选择图片。发送前必须打开配置面板里的“安全”开关。开关关闭时，带图请求会被拒绝，并显示错误提示。图片会发给厂商，程序不做本地识别。

联网搜索。输入条左侧有“联网搜索”开关。打开后，模型可以自主调用搜索工具。搜索过程显示“联网中…”。本轮命中来源后，消息上方出现“已联网 · N 条来源”的胶囊。点胶囊查看来源标题和链接。DeepSeek 使用内置搜索，不需要额外配置。其他厂商需要在模型菜单的“联网搜索”行点“配置…”，填写搜索端点和搜索密钥。端点或密钥缺失时，开关会提示未就绪。

资料库。输入条有“资料库”入口。点开后选择要参与本轮检索的小库。可以挂载多个小库。首次挂载会弹出同意说明。未同意时只能本地入库，不会建立向量，也不会把内容发给模型。挂载成功后按钮显示“资料库 · N”。回答完成后，消息下方显示引用来源，包含文件名和定位信息。

消息操作。助手消息下方有“复制”“重新生成”“分享文字”“分享图片”。点“复制”复制整条回答，按钮短暂显示“已复制”。点“重新生成”删除最后一条助手消息，并用最后一条用户消息重新请求。生成中不能重新生成。重新生成不会重复写入用户消息。点“分享文字”同样复制整条回答。点“分享图片”打开“保存消息图片”对话框，把当前消息气泡截成 PNG 保存。保存失败时检查目标目录是否可写。

Token 与耗时。助手消息底部显示本轮 `Token` 和 `耗时`。厂商没有返回用量时显示 `—`。失败或中断的轮次也可能没有数据。

Markdown 显示。助手回答中的标题、列表、粗体、行内代码和代码块会按 Markdown 渲染。回答里的链接交给系统默认浏览器打开。

错误提示。请求失败时，消息流上方出现错误横幅。常见错误包括：Key 未配置、Key 无效、余额不足、请求频率受限、网络不可达、厂商返回 400、模型不支持图片。按提示修正后重新发送。错误横幅不会自动消失，发送下一轮或手动关闭后消失。

对话不会自动保存成文件。所有消息写入本机数据库。关闭程序再打开，会话仍在。数据库损坏或磁盘不可写时，程序降级为仅内存可用，并在界面提示持久化失败。

### 角色卡

入口在左侧侧栏的「角色卡」区块，位于会话列表和底部导航之间。每张卡片显示头像、名称和它绑定的模型。

套用。点卡片即可套用，模型、思考档位、系统提示词三项一起生效，卡片右侧出现「已套用」并高亮。头像只作展示，不影响回答。未套用任何角色卡时没有高亮。

管理。区块右上角点「管理」打开面板。

- 新增：填名称（必填，不可与已有角色卡重名）、提示词（可留空）、选厂商 / 模型 / 档位，点头像位可以裁剪一张 512×512 的头像。厂商、模型、档位三项的「默认」表示套用时跟随你当前正在使用的设置，只有你改选后才锁定成具体值。
- 编辑：改任何字段后保存。如果改的是当前生效的角色卡，提示词会立即跟着更新。
- 删除：点「删除」后还要再点一次确认。删掉的若是当前生效卡，模型和档位保持不变，系统提示词清空，并弹一次提示。
- 导出：把全部角色卡存成一个 JSON 文件。文件名没写后缀时自动补 `.json`。
- 导入：选一个 JSON 文件。若有同名角色卡，面板会列出冲突名字，让你选「覆盖同名」「跳过同名」或「取消导入」，你不选就不会写入任何数据。

什么时候生效。切换角色卡只影响下一条消息，不会改写已有历史。系统提示词随每次请求下发，优先级最高，排在当前时间、技能和资料库检索内容之前。提示词留空的角色卡不会下发空的系统消息。

重启后回到未套用。当前生效的角色卡只记在内存里，关掉程序再打开需要重新点一次。

### 技能仓库

入口在左侧导航「技能仓库」。内置技能随程序发布，导入的技能放在你的数据目录下。

调用模式。页面顶部切换「自动」和「手动」。

- 自动：按技能声明的触发词匹配你的输入，最多同时注入 2 个已启用技能，优先级按触发词在输入中首次出现的位置。
- 手动：在对话输入区选择技能，只对这一次发送生效。

启停与删除。列表里每个技能可以单独启用或禁用，禁用后永不注入。内置技能不能删除；导入的技能可以删，删掉只影响本地目录。

导入技能包。点右上角「导入技能包」选一个 `zip`。要求：包内必须有 `manifest.json` 和 `skill.md`；`manifest.json` 需包含 `id`（只能用字母、数字、连字符）、`name`、`version`、`entry`，自动模式还要求非空的 `triggers` 字符串数组。包体不超过 20 MB，解压后不超过 100 MB，条目不超过 2000。和内置技能同 id 会被拒绝，需要改名；和已有导入技能同 id 会按覆盖更新。校验不通过时页面内会给出具体原因，不会写入半个包。

注入顺序。技能内容排在角色卡提示词和当前时间之后、资料库检索内容之前。全部技能内容合计超过 4000 字符会被硬截断，且不会提示。

## 5. 资料库：把自己的文件变成 AI 的参考书

资料库位于左侧导航“资料库”。页面分左右两块：左侧是小库列表，右侧是文件列表。检索参数、服务配置、隐私、成本和库内搜索都在顶栏“配置”打开的右侧抽屉里。

创建小库。在左侧“新建小库名称”输入框里填名称，点“+ 新建小库”。名称为空时按钮不可用。小库用来分组文件。一个文件可以属于多个小库。

选择小库。点左侧小库条目。右侧文件列表切换到该库。

删除小库。点小库条目右侧的 `×`，底部出现红色确认条“删除小库只删索引，不删原文件”。点“确认删除”才会删除，点“取消”放弃。删除小库不会删除你的原始文件。

导入文件。点“导入文件”，在文件选择器里多选文件。也可以把文件直接拖到文件区域。拖入时显示“松开即可导入到「库名」”。导入会复制一份库内副本，原文件保持不动。

支持导入的扩展名：`txt`、`md`、`markdown`、`csv`、`tsv`、`json`、`log`、`pdf`、`docx`、`xlsx`、`pptx`、`jpg`、`jpeg`、`png`、`webp`、`gif`、`bmp`。

体积上限：文档类单次解析上限 1 GB；文本、Office、PDF 需要整文件载入内存，实际超过 512 MB 会提前拒绝并提示拆分；图片单张上限 128 MB。

视频文件只登记，不解析。遇到视频会标记为“不支持”。

关联文件夹。点“关联文件夹”，选择本地文件夹。程序只记录引用并建立索引，不复制文件。文件夹条目可以“重建快照”或“解除关联”。解除关联不会删除原文件夹。

重建索引。点“重建索引”重新处理当前小库全部文件。索引进行中按钮区出现“停止”。点“停止”结束当前队列，已完成的文件保留索引。

移除文件。文件行右侧有“移除”。点它立即移除库内记录和索引，没有二次确认。原文件不受影响。如果文件来自关联文件夹，原文件夹也不会被修改。

文件状态。列表里每个文件显示状态标签：

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| 已索引 | 文本、向量、关键词索引都已建立 | 可以直接参与检索 |
| 待建向量 | 文本已切分，缺少 embedding 服务或 Key | 在配置抽屉里配置 embedding，再重建 |
| 待索引 | 已入库，等待处理 | 等待队列，或点“重建” |
| 无文本层 | PDF 没有可提取文字，或解析器未启用 | 换带文本层的 PDF；本版本不做 OCR |
| 索引失败 | 解析、切分或向量化报错 | 看错误文字，修正配置后点“重建” |
| 内容已变化 | 关联文件夹里的文件被修改 | 点文件夹的“重建快照” |
| 不支持 | 扩展名不在支持范围 | 转换成支持的格式再导入 |

文本切分参数。默认按 700 字符切分，相邻片段重叠 120 字符。重叠值可以调到切分尺寸的一半。参数改大后建议重建索引，否则旧片段仍按旧参数切分。

内容向量化。配置抽屉里有“内容向量化（embedding）”区块。选择厂商、填写模型名，必要时展开“高级”填写服务地址。点“拉取模型”可以请求厂商模型列表。点“保存 embedding 配置”保存。Key 单独点“保存 embedding Key”保存。保存后点“验证可用性”发一次最小请求。验证结果分为有效、无效、无法验证。修改配置或换 Key 后需要重新验证。

图片描述。配置抽屉里有“图片描述（caption）”区块。图片入库后，需要视觉模型生成描述才能参与检索。配置方式与 embedding 相同：选厂商、填模型、可选服务地址、拉取模型、点“保存图片描述配置”、点“保存图片描述 Key”、点“验证可用性”。验证会发送一张内置小图与短提示，不受资料库图片外发同意开关影响，可能产生极小费用。没有配置视觉模型时，图片显示“待索引”或缺少视觉模型的提示。

成本预估。配置抽屉底部显示文本 token 数、图片数量、首次建向量费用、图片描述费用和每次对话注入上限。费用是参考值，按 `resources/pricing.json` 计算，不包含厂商折扣和汇率变化。

库内搜索。配置抽屉底部有“库内搜索（本地关键词）”。输入关键词后回车，结果显示文件名、定位和摘要。搜索只查本地索引，不调用模型。

同意与撤回。首次启用资料库、首次挂载小库或导入后需要外发时，会弹出同意层。同意层说明哪些内容会离开本机、发给谁、如何撤回。点“同意并启用”才会建立向量和发送内容。点“暂不启用”只做本地入库。撤回入口在配置抽屉“检索与隐私”里的“撤回同意”。撤回后不再发送任何资料库内容，已有本地索引保留。

停用资料库。配置抽屉里有“停用资料库”。停用后对话不再挂载小库，文件与索引保留。

检索参数默认值：

| 参数 | 默认值 | 范围 | 作用 |
| --- | --- | --- | --- |
| Top-K | 6 | 1–30 | 最终注入的片段数 |
| 每文件片段上限 | 2 | 1–10 | 防止单个文件占满上下文 |
| 注入 token 预算 | 2000 | 200–20000 | 每轮注入资料库内容的上限 |
| 相似度阈值 | 0.30 | 0–1 | 低于阈值的片段不注入 |
| 邻居扩展 | 1 | 0–2 | 命中片段前后各取几段 |
| 关键词兜底 | 开 | 开/关 | 向量召回不足时用 FTS5 补 |
| 切分尺寸 | 700 | 200–2000 | 每个片段的目标字符数 |
| 片段重叠 | 120 | 0–切分尺寸一半 | 相邻片段重叠字符数 |

参考资料模式参数：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 单文件预算 | 20000 token | 一个文件最多注入多少内容 |
| 全局预算 | 100000 token | 本轮所有文件合计上限 |
| 回答预留 | 2000 token | 留给模型回答的空间 |
| 文件聚合权重 | 0.05 | 文件级排序时命中数量的加权 |
| 未知窗口回退 | 32768 token | 模型上下文窗口未知时的保守值 |

文件级注入按“全文 → 章节 → 片段”逐级降级。全文放得下就注入全文；放不下就按章节选；再放不下就回到片段。降级原因会显示在来源明细里。

资料库相关错误：

- 导入后一直“待建向量”：没有配置 embedding，或没有同意外发。先同意，再配置服务和 Key。
- 图片一直“待索引”：没有配置视觉模型，或模型不支持图片。
- PDF 显示“无文本层”：PDF 是扫描件，或当前构建没有 PDFium。换文本版 PDF，或使用带 PDFium 的发布包。
- 索引失败并提示 HTTP 400：检查 embedding 模型名和服务地址。通义批量上限问题在 v0.2.6 已修复。
- 检索没有结果：降低相似度阈值，或确认小库已挂载、文件状态是“已索引”。
- 提示“内容已变化”：关联文件夹里的原文件变了，点“重建快照”。

## 6. 个性化

入口在左侧导航“个性化”。页面从上到下是主题、字体、背景、头像、开屏动画、帮助和恢复默认。

主题。下拉框里有“Nocturne 琥珀”和“Daylight 浅蓝”。默认是 Nocturne 琥珀。切换后立即生效，重启后保持。主题只替换颜色和圆角等设计令牌，不改变布局。

字体。字体区的下拉框列出系统已安装字体。选中后点“使用此字体”应用。点“导入字体文件…”选择本地字体，支持 `ttf`、`otf`、`ttc`，单文件不超过 20 MB。导入后回到下拉框选中该字体，再点“使用此字体”。点“恢复默认”回到系统默认字体。字体文件复制到本机 `assets` 目录。

背景。点“选择背景图…”导入图片。支持 `png`、`jpg`、`jpeg`、`webp`、`bmp`、`gif`、`svg`，单文件不超过 128 MB。背景按填充方式铺满窗口。点“清除背景”移除。

头像。点“选择头像…”选择图片，进入裁剪界面。拖动和缩放取景框，确认后输出 512×512 的方形头像。头像显示在顶栏右侧。点“清除头像”恢复默认的“猫”字占位。图片无法读取时裁剪层自动关闭，页面顶部弹出提示“头像图片无法读取，请换一张图片。”；裁剪结果生成失败时顶部弹出对应提示。

开屏动画。默认使用内置开屏。内置开屏按当前主题播放，约 3.5 秒，带音效，右下角有“跳过”。点“选择视频…”可以换成本地视频。支持 `mp4`、`mov`、`m4v`、`webm`、`mkv`、`avi`，单文件不超过 1 GB。设置自定义视频后以视频为准，内置开屏不再播放。点“预览”立即播放一次。点“清除”删除自定义视频，回到内置开屏。

开屏开关。“启动时播放”控制下次启动是否播放。“播放音效”控制内置开屏和自定义视频的声音。关闭“启动时播放”后，预览仍然可用。

帮助。页面底部点“帮助”，弹层显示开发者、联系方式、快速上手步骤和手册位置。点“打开用户手册”会用系统默认程序打开手册文件。程序会依次查找：安装目录 `docs/USER_GUIDE.md`、安装目录 `USER_GUIDE.md`、开发仓库的 `docs/USER_GUIDE.md`。都找不到时提示“未找到用户手册，请确认安装包完整”。按 Esc 或点“关闭”退出弹层。

恢复默认。点“恢复全部默认”会重置主题、字体、背景、头像和开屏，并删除已导入的字体、背景、头像与开屏视频文件。点击即执行，没有二次确认，无法撤销。

个性化错误：

- 字体导入失败：文件超过 20 MB，或格式不是 `ttf/otf/ttc`。
- 背景导入失败：文件超过 128 MB，或格式不支持。
- 视频无法播放：编码不受支持。换 H.264 编码的 `mp4`。
- 头像裁剪失败：图片损坏或尚未解码完成。换图片重试。
- 主题切换后部分文字看不清：切回默认主题，并把这个主题名和截图发给开发者。

## 7. 窗口操作

窗口使用自绘标题栏，高度 38 像素。左上角显示品牌图标、`MeowAi` 和当前页名。右上角是最小化、最大化/还原、关闭三个按钮。

拖动窗口。按住标题栏空白区域拖动。双击标题栏在最大化和还原之间切换。

侧栏折叠。侧栏展开宽度 228 像素，折叠后 64 像素。展开态顶部有折叠按钮，折叠态顶部有展开按钮。折叠后只显示图标。

页面切换。侧栏顶部是“对话”，中间夹着角色卡区块（见第 4 章「角色卡」），底部是“个性化”“资料库”和“技能仓库”。点导航项切换页面。对话页顶部额外显示模型胶囊和“配置”。资料库页顶部右侧有“配置”，点开右侧抽屉。技能仓库页顶部切换自动 / 手动模式，右上角是“导入技能包”。

资料库配置抽屉。抽屉从右侧滑出，宽度最多 440 像素。点遮罩、点“关闭配置”或再点顶栏“配置”可以关闭。抽屉打开时仍可看到左侧文件列表。

窗口尺寸。默认 1180×760，按屏幕可用区域收缩。最小尺寸约 820×560；屏幕较小时下限会降低。可用屏幕小于 1200×820 时，程序启动后自动最大化。

切换显示器或远程桌面分辨率变化时，窗口会自动收回到当前屏幕内。

## 8. 数据与隐私

数据目录：`C:\Users\<你的用户名>\AppData\Roaming\MeowAi\MeowAi`。

目录内容：

| 路径 | 内容 |
| --- | --- |
| `config.json` | 厂商、模型、档位、资料库参数、联网配置、主题与个性化设置。不含 API Key |
| `metadata.db` | 会话、消息、资料库文件记录、片段、向量、引用、文档与章节、角色卡。当前 schema 版本 5 |
| `secure/` | 加密后的 API Key 保险库，扩展名 `.vault` |
| `library/` | 导入文件的库内副本 |
| `assets/` | 导入的字体、背景、头像、开屏视频 |
| `categories/` | 文件分类预留目录，当前版本未写入 |
| `backups/` | 修改前备份预留目录，当前版本未写入 |
| `skills/` | 导入的技能包解压目录。内置技能从资源包读取，不落这里 |
| `skills_state.json` | 技能启停与调用模式（`{version, mode, enabled}`） |

密钥保护。Windows 上使用 DPAPI 按当前用户加密。密文换到其他 Windows 用户或其他电脑通常无法解密。`config.json`、日志和界面属性都不保存明文 Key。

不会上传的内容：原始文件、库内副本、会话数据库、配置、API Key。会外发的内容：对话消息、资料库检索命中的片段、你确认上传的图片、建立向量时的片段文本、生成图片描述时的图片。外发目标是你选择的厂商。

删除数据。删除单个会话在会话列表点 `×`，立即生效。删除小库只删索引和库内副本。移除文件只删库内记录。恢复默认外观会删除 `assets` 里的导入资源。彻底清空需要关闭程序后手动删除整个数据目录。

隐私限制：

- Linux 和 macOS 平台适配层不具备真实密钥加密能力。当前没有这两个平台的安装包。
- Web 平台适配层明确拒绝保存 Key。
- 资料库同意只覆盖资料库内容外发。对话消息本身仍会按你的提问正常发给厂商。
- 联网搜索会把查询词发给你配置的搜索服务。

## 9. 常见问题

问：为什么第一次打开没有配置向导。
答：当前版本把配置放在对话页顶部的“配置”面板。按第 3 节操作即可。

问：Key 保存后为什么显示“密钥已就绪（未校验）”。
答：保存只代表写入本机保险库。点“验证”才会向厂商发一次最小请求。验证通过后显示“已验证”。

问：验证提示“无法验证”是不是 Key 错了。
答：不一定。429、断网、超时都会显示无法验证。换网络后重试，或直接发一条消息看是否成功。

问：为什么发图按钮或输入框不可用。
答：当前模型没有声明视觉能力。换支持视觉的模型。即使模型支持，也要打开配置面板里的“安全”开关。

问：为什么资料库文件一直是“待建向量”。
答：没有同意内容外发，或没有配置 embedding 服务和 Key。先在配置抽屉里同意，再保存 embedding 配置与 Key，最后重建索引。

问：删除小库会不会删我的文件。
答：不会。删除小库只删索引和库内副本。关联文件夹里的原文件也不会被删除。

问：PDF 为什么显示“无文本层”。
答：扫描版 PDF 没有可提取文字，当前版本不做 OCR。另外，源码构建需要本地放置 PDFium 才能解析 PDF 文本层。发布安装包是否内置 PDFium 以实际产物为准。

问：为什么没有应用内升级。
答：升级功能仍是骨架。`UpdateManager` 只有接口，检查更新会返回失败。新版本需要手动下载安装包覆盖安装。

问：为什么技能没有出现在对话里。
答：先确认三件事。一是技能是否处于启用状态（技能仓库列表里每个技能都能单独启停）。二是调用模式：「自动」要求技能声明了触发词且你的输入里含有该词；「手动」需要你在对话输入区主动选。三是技能内容合计超过 4000 字符会被硬截断，长技能可能只剩开头。

问：角色卡套用了，重启后为什么又变回去了。
答：当前生效的角色卡只记在内存里，不写配置文件，所以重启回到未套用。这是有意设计——和「系统提示词不落盘」保持一致。重新点一次卡片即可。

问：角色卡重启不保留，那提示词会不会被写进会话记录。
答：不会。系统提示词只随请求下发，不进数据库，也不会出现在历史消息里。

问：为什么 Web 端不能保存 Key。
答：Web 平台适配层明确拒绝保存密钥。当前只交付 Windows 桌面版。

问：删除会话为什么没有确认。
答：当前交互是点击即删。删除后无法恢复。需要保留的会话不要点 `×`。恢复全部默认外观同样是点击即执行。

问：安装向导为什么是英文。
答：安装脚本只配置了英文语言包。程序界面是中文。

问：数据能不能直接拷到另一台电脑。
答：会话和资料库可以拷，但 API Key 受 DPAPI 保护，通常无法在新电脑解密。到新电脑重新填 Key。

问：程序崩溃或界面空白怎么办。
答：先重启程序。仍然异常时，记录版本号、Windows 版本、操作步骤和错误文字，发给开发者。不要发送 API Key 或包含隐私的文件。
