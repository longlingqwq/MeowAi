## 1. 先认识一下 MeowAi

MeowAi 是一个装在你自己电脑上的 **AI 对话助手**。它和网页版 AI 最大的区别是：

- **可以带一个"资料库"**：把自己的 PDF、Word、Excel、PPT、图片放进去，提问时 AI 会先翻你的资料，再结合自己的知识回答，并告诉你"这句话来自哪个文件、第几页"。
- **数据在自己电脑上**：对话记录、资料库文件、配置都保存在本机；只有你主动提问时，问题和你选中的资料内容才会发送给你配置的 AI 厂商。
- **每个人一份独立数据**：没有账号体系，发给朋友后各用各的，互不影响。

它**不是**什么：
- 不是本地大模型，电脑不用装显卡模型；AI 能力来自你填的厂商 API。
- 不会自动修改或删除你的原始文件。
- 目前不解析视频，也不支持扫描版 PDF 的文字识别（OCR）。

## 2. 安装（第一次使用）

### 2.1 系统要求
- Windows 10 / 11，64 位。
- 能正常上网（需要访问你选择的 AI 厂商接口）。

### 2.2 安装步骤
1. 双击 `MeowAi-Setup-0.2.6.exe`。
2. 如果 Windows 弹出蓝色提示"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**（这是新软件常见的提示，不是病毒）。
3. 一路点 **Next / Install**，完成后可勾选立即启动。
4. 安装位置默认是 `C:\Users\<你的用户名>\AppData\Local\Programs\MeowAi`，**不需要管理员权限**。
5. 桌面和开始菜单会生成 MeowAi 快捷方式。

### 2.3 卸载
Windows「设置 → 应用 → 已安装的应用 → MeowAi → 卸载」。
卸载**不会删除**你的对话记录和资料库，需要彻底清理时见 §9.3。

## 3. 第一次打开：5 分钟完成配置

打开后界面分为三块：**左侧导航**（对话 / 资料库 / 个性化）、**中间内容区**、**右上角标题栏按钮**。

### 第一步：选 AI 厂商
在「对话」页顶部找到接入卡，点右侧的 **配置** 展开。

1. **厂商**：下拉里可选 DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI、Anthropic 等。
2. **模型**：选完厂商后，在"模型"下拉里选具体型号（不需要手写模型名）。
   - 菜单里的型号可以用鼠标停留 1 秒打开二级菜单，查看思考档位等说明。
   - 内置清单里没有的型号，可选「自定义」，自己填 API 链接和模型名。
   - 点「拉取清单」可向厂商实时获取最新型号；失败也不影响内置清单。

### 第二步：填 API Key
1. 到厂商官网申请一个 API Key（形如 `sk-...`）。
2. 粘贴到接入卡的密钥框，点 **保存**，再点 **验证**。
3. 看到 **密钥有效** 就说明配置成功。

三种验证结果要分清：
| 结果 | 含义 | 怎么办 |
|---|---|---|
| 密钥有效 | 可以使用 | 直接开始对话 |
| 密钥无效 | Key 填错、失效或没有权限 | 重新复制 Key |
| 无法验证 | 网络超时、限流、断网 | **不代表 Key 错了**，稍后重试 |

> Key 保存在本机加密保险库（Windows 系统级加密），不会明文写在配置文件里，日志里也不会出现。

### 第三步：发第一句话
在底部输入框输入"你好，介绍一下你自己"，点 **发送** 或按回车。回答会像打字一样逐步出现；想停止就点 **中断**。

## 4. 日常对话

| 想做的事 | 怎么做 |
|---|---|
| 开新对话 | 左侧顶部「＋ 新对话」 |
| 切换历史对话 | 点左侧会话标题 |
| 删除对话 | 鼠标移到会话上，点右侧 ✕ |
| 停止生成 | 生成中在输入框右侧点「中断」 |
| 换模型 | 点底部的模型名胶囊，或接入卡里的模型下拉 |
| 调整思考强度 | 底部模型菜单里选 关 / 低 / 中 / 高（仅支持思考的模型显示） |
| 发图片 | 先在接入卡打开"允许上传图片"，并在「附图」框填图片路径；**未确认时图片不会上传** |

关闭软件再打开，历史对话仍然在（保存在本机数据库）。

### 联网搜索
输入区上方的「联网」开关打开后，AI 可以自行搜索网页并参考结果回答，回答上方会显示来源条数。
没有内置搜索能力的厂商，可在联网设置里填写自定义搜索接口。联网失败会自动退回普通对话，不会卡死。

## 5. 资料库：把自己的文件变成 AI 的"参考书"

这是 MeowAi 最有价值的功能。举例：你是物业工程经理，可以把施工规范、项目台账、验收标准放进一个叫「工程用」的小库；提问时挂载它，AI 就会先查这些资料。

### 5.1 建一个小库
1. 左侧点「资料库」。
2. 输入名称（如"工程用"）→ 点「＋ 新建小库」。
3. 一个文件可以同时属于多个小库。

### 5.2 放文件进去（两种方式）

| 方式 | 实际做了什么 | 适合 |
|---|---|---|
| **导入文件** / 直接把文件拖进中间列表 | 复制一份到资料库目录，原文件不动 | 想长期保存、独立管理 |
| **关联文件夹** | 只记录引用并生成快照，不复制文件 | 文件本来就在某个项目文件夹里 |

支持：`txt / md / csv / json / PDF（有文字层）/ docx / xlsx / pptx`，图片 `jpg / jpeg / png / webp / gif / bmp`。
**扫描版 PDF**（整页是图片）没有文字层，会显示"无文本层"，当前无法检索。

### 5.3 配置两个"幕后服务"
资料库靠**语义检索**工作，需要两类接口（都走 API，可以复用你已有的 Key）：

1. **Embedding（向量）**：把文字变成"语义坐标"，让 AI 能找到意思相近的内容。
   - 不配置也能用：文件照常入库，检索自动降级为**关键词搜索**，只是没那么聪明。
2. **视觉模型（图片描述）**：图片入库时先生成一段文字描述，描述参与检索。
   - 图片内容会发给厂商，**需要你单独同意**；不同意则图片显示"待索引"。

配置好后点 **重建索引**，等待状态变成「已索引」。

### 5.4 看懂状态

| 状态 | 意思 | 处理 |
|---|---|---|
| 已索引 | 可以被检索 | — |
| 待建向量 | 缺少 embedding 配置 | 配置后重建索引 |
| 待索引 | 图片缺少视觉模型 / 未同意 | 配置或同意后重建 |
| 无文本层 | 扫描版 PDF | 需要 OCR（暂不支持） |
| 索引失败 | 文件损坏或格式异常 | 看提示，必要时重新导入 |
| 内容已变化 | 关联文件夹里的源文件被改过 | 点「重建快照」 |
| 不支持 | 视频等 | 当前不做 |

### 5.5 让 AI 用上资料库
1. 在「对话」页输入区上方点「资料库」挂载入口，打开要用的一个小库的开关。
2. 正常提问即可，**检索是软件自动完成的**，不需要你跟 AI 说"请翻我的文件"。
3. 回答下方会列出：
   - **来源**：文件名 + 页码 / 工作表 / 行号；
   - **注入**：这次用了哪几个文件、是整份文件还是某一章节、大约多少 token、是否被截断。
4. 首次启用资料库、首次挂载、图片外发时会弹出同意确认，说明哪些内容会离开本机。

### 5.6 参考资料模式：AI 到底看到了多少？

这是 v0.2.6 的核心改进，用大白话解释：

1. **先找文件**：根据你的问题，在所有已挂载的小库里找出最相关的**几个文件**（不是只找零散句子）。
2. **小文件整份给**：文件不大，就把**全文**交给 AI，细节不丢。
3. **大文件挑章节**：文件太大时，按标题 / 工作表 / 页自动挑出相关的一章或几章。
4. **预算不够再退片段**：如果连章节都放不下，才退回最相关的片段，并在界面上标记"已截断"。
5. **资料只是参考**：AI 可以结合自己的知识或联网结果回答；资料里没有的内容，它会说明而不是硬编。

> 每次提问都会重新发送资料内容，因为大模型接口是"无记忆"的。软件会尽量把重复内容放在提示词前部，让厂商的缓存机制降低费用。

### 5.7 预算怎么调（资料库页右侧）

| 参数 | 默认 | 作用 |
|---|---|---|
| 单文件预算 | 20000 tokens | 一个文件最多占多少上下文 |
| 全局预算 | 100000 tokens | 本轮所有相关文件合计上限 |
| 上下文预留 | 2000 tokens | 留给历史对话和回答的空间 |
| 未知窗口估算值 | 32768 tokens | 厂商没告知模型上下文大小时使用 |
| Top-K | 6 | 最终最多注入多少段 |
| 每文件片段上限 | 2 | 防止一个大文件霸榜 |
| 相似度阈值 | 0.30 | 低于该值的内容丢弃 |
| 邻居扩展 | 1 | 命中片段前后各带一段，避免语义被切断 |
| 关键词兜底 | 开 | 向量服务不可用时自动改用关键词搜索 |

软件会先检测模型的上下文窗口，再自动把预算"钳制"到安全范围；模型窗口未知时使用上表的"未知窗口估算值"。

## 6. 个性化

左侧「个性化」页可以：

- **主题**：内置主题1（Nocturne 琥珀），切换立即生效并记住。
- **字体**：用系统字体，或导入 `.ttf / .otf / .ttc` 字体文件。
- **背景图**：png / jpg / webp / bmp / gif / svg，自动压暗保证文字看得清。
- **头像**：显示在右上角，仅本机可见。
- **开屏动画**：选择本地视频，可控制启动时是否播放、是否带声音。
- **帮助**：页面底部的「帮助」按钮会弹出开发者信息、联系方式和快速上手指引。
- **恢复全部默认**：会清理已导入的字体、背景、头像和开屏视频。

## 8. 数据与隐私

### 8.1 数据存在哪里
默认目录：`C:\Users\<用户名>\AppData\Roaming\MeowAi\MeowAi\`

| 内容 | 位置 |
|---|---|
| 非敏感配置（模型、参数、挂载关系） | `config.json` |
| API Key（加密保险库） | `secure\` |
| 导入时复制的资料库文件 | `library\` |
| 字体 / 背景 / 头像 / 开屏视频 | `assets\` |
| 会话历史、索引、向量 | 数据库文件（同目录） |

### 8.2 什么会离开本机
- 你的**提问内容**会发给你选择的模型厂商。
- 使用资料库时，**入库的文本片段、图片描述、命中的资料内容**会发给 embedding / 视觉 / 对话厂商。
- 开启联网时，搜索词与网页请求会发往搜索服务和目标网站。

以上行为都有明确的同意提示，也可以随时撤回。

### 8.3 不会发生的事
- 不会把 API Key 明文写进配置或日志。
- 不会因为删除小库而删除你的原始文件。
- 不会静默上传图片；没同意就拒绝发送。

### 8.4 备份与迁移
关闭软件后，把上面整个数据目录复制到新电脑的同位置即可（Key 使用 Windows 用户级加密，换电脑后需要重新填一次 Key）。

## 9. 常见问题

**Q1：双击安装包没反应 / 提示不安全？**
看是否被安全软件拦截；Windows 蓝色 SmartScreen 提示点「更多信息 → 仍要运行」。

**Q2：打开后界面很空？**
正常。先按 §3 配置厂商和 Key，再新建对话。

**Q3：验证 Key 显示"无法验证"？**
这是网络超时、限流或断网，不代表 Key 错误。检查网络/代理后重试。

**Q4：对话报 401 / 403？**
Key 无效、过期或无权限，重新复制正确的 Key。

**Q5：PDF 一直"无文本层"？**
它是扫描件。当前不做 OCR，可以先用别的工具转成有文字层的 PDF。

**Q6：导入文件后没反应？**
确认已选中小库；工具栏下方会显示成功数量或失败原因。也可以直接拖文件进列表。

**Q7：AI 说资料库里没找到依据？**
依次检查：① 是否配置了 embedding；② 是否挂载了小库；③ 文件状态是否"已索引"；④ 相似度阈值是否太高。

**Q8：图片一直"待索引"？**
缺少视觉模型配置，或没有同意图片外发。`.webp` 在个别环境缺插件也可能失败。

**Q9：回答很慢？**
取决于厂商当前速度；可以换模型、降低思考档位，或减少单文件预算。

**Q10：大文件导入时界面卡一下？**
解析目前在界面线程执行，属已知限制，稍等即可。

**Q11：AI 会改我的文件吗？**
不会。资料库是只读的。

**Q12：能搜索视频内容吗？**
不能，视频暂未实现。

**Q13：卸载后数据还在吗？**
在。需要彻底清理请手动删除 §8.1 的数据目录。

**Q14：能装到手机或 Mac 上吗？**
当前提供 Windows 版；Android 与网页端仍在开发中，iOS 只规划网页端。
