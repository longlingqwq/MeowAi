# 示例技能

本文件是内置 Skill 的文档正文占位，同时作为**技能包格式的范本**。

## 一、目录与字段

- 内置技能：`resources/skills/<id>/`，运行期经 `:/skills` 读取，**随安装包发布、不可修改**。
- 用户技能：`%APPDATA%\MeowAi\skills\<id>\`，由「技能仓库」导入 zip 生成。
- 每个技能目录必须包含 `manifest.json` 与 `skill.md`，`manifest.json` 字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，只允许字母、数字与连字符；须与目录名一致 |
| `name` | 是 | 展示名 |
| `version` | 是 | 版本号 |
| `description` | 否 | 一句话说明 |
| `entry` | 是 | 技能文档相对路径，导入时必须为 `skill.md` |
| `triggers` | 自动模式必填 | 字符串数组，用于自动匹配；缺省或空数组的导入包会被拒绝 |

## 二、两种调用模式

- **自动模式**：对用户输入做触发词匹配（不区分大小写，中文按子串匹配），
  命中后按「触发词首次出现位置」排序，最多取前 2 个**已启用**技能，
  把 `skill.md` 注入到 system 消息，总量上限 4000 字符（超出直接截断）。
- **手动模式**：在对话输入区手动选择技能，只对**本次发送**生效，发送后清空。
- 禁用状态的技能在两种模式下都不会被注入。

## 三、导入校验（技能仓库）

1. 单包 ≤ 20 MB，解压后 ≤ 100 MB，条目数 ≤ 2000；
2. zip 内不得出现绝对路径、盘符或 `../`（目录穿越直接拒绝）；
3. `manifest.json` 必须唯一，字段口径同上；
4. `skill.md` 必须存在且非空；
5. 与内置技能同 `id` 会被拒绝（内置优先），请改名后重试。

## 四、示例

```json
{
  "id": "my-skill",
  "name": "我的技能",
  "version": "1.0.0",
  "description": "一句话说明这个技能做什么",
  "entry": "skill.md",
  "triggers": ["关键词一", "关键词二"]
}
```

打包时把 `manifest.json` 与 `skill.md` 放在 zip 根目录（或同一个子目录）即可。
